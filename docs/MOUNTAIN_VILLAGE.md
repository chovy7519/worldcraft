# 山地村落实验 v2 · 宅地与住户

## v2 新增操作

点击左侧住宅或使用“选择住宅”列表，查看该户宅地面积、临路边长、等高线方向、院门、入户步道和三段基础标高；“定位住宅”将两侧视图同步聚焦，使用“适配视图”恢复。宅地图层可以关闭，回放到尚未出现的住宅时选择自动切回可见住户。

右侧默认使用“坡度随机布局”对照，仍可切回旧网格基线。两侧按相同阶段显示实际生成数量，容量不足不会补足或隐藏。

## v2 宅地与建筑规则

- **宅地表示**：2.5m 栅格、四邻域，水域、道路缓冲和场地边缘为障碍；每个住宅和接路方向预留初始区域。
- **有向成本扩张**：使用多源 Dijkstra 竞争单元归属。每步成本为 `2.5 × (1 + 0.45 × (1 − alongContour) + 3 × absHeightDifference/2.5)`，沿等高线更便宜，跨高差更贵。每户最大半径 30m、扩张成本上限 29；未分配区域保留为公共/自然地面，不强制全场铺满。
- **几何与连通**：每个单元仅归一户；保留与住宅相连的四邻域分量，取消内部边得到外边界/洞环；单元几何是权威数据。宅地为阶梯状近似多边形，尚未进行边界平滑。
- **临路与院门**：宅地与道路缓冲栅格相接的边作为临路边，选择靠近原接路点的一条作为院门。临路长度是栅格边界的平面长度，不是精确道路工程边线长度。
- **住宅朝向**：以局部高程梯度的垂直方向作为长轴，即沿等高线；正面朝向接路点。建筑始终为 10×8m，旋转后的中心与四角参与坡度、水域检查。
- **入户路径**：在本户单元内 BFS 连接门口与院门，形成“门—院内步道—院门—道路接入点”关系；院门到道路接入点单独保存为 roadConnection。入口踏步是离散视觉表达，未进行完整踏步净宽/踏高法规校核。
- **阶梯基础**：沿坡向将基础分为三条带，各自按四角最大地形高度设置顶面；在宅地允许范围内沿长边最多外展 1m，空间不足时缩回主体宽度。主体楼面位于最高基础之上。仍为视觉体量，不包含结构计算。
- **围界预览**：所选宅地显示 0.7m 的低围界，院门附近留口；其线形沿栅格边界，尚未做真实砌筑或排水设计。
- **院落余地**：检查器显示宅地面积减去 80m² 建筑基底的余地；该值包含步道、基础等，不等于净可用花园面积。
- **回放边界**：宅地在完整道路和住户布局完成后计算；时间轴按住宅出生阶段显示最终宅地，不模拟地籍边界随每个历史阶段重新变化。

实现位于 `src/village-households.mjs`；主生成模型标识升级为 `mountain-households-v2`、JSON version 2。示例 `examples/mountain-households-seed42.json` 包含本轮完整宅地与基础数据；旧样例保留。

## v2 坡度随机对照

共用地形、目标数量、建筑尺度、坡度/水域/间距约束、道路纵坡阈值、寻路、宅地和基础规则。使用独立确定性随机流，以随机顺序从可行位置选择住宅，移除平缓偏好、道路距离兴趣、中心吸引与邻里偏好评分；也移除适应性模式的 95m 候选接路搜索距离限制。道路仍需接入且不得侵入住宅。两种方法的住宅可位于不同区域，因此这是控制规则的诊断实验，尚不是控制所有随机因素的严格消融实验。

默认种子 42：两者各 50 户，建筑与道路均无坡度/水域违规；建筑最大坡度均值约 7.7° / 11.5°。结果仅描述该合成场地，不能推断普遍优越性。

最终 `npm run verify` 为 52/52 项通过，独立 HTML 构建和原城市几何检查通过。实际浏览器导出已逐字段核对；`node scripts/verify-village-download.mjs` 可复核随附样例，也可传入导出 JSON 路径。跨 JS 引擎三角函数允许 1e-10 数值容差；几何坐标按毫米保存。

本轮还测试种子 0、7、42、81 × 坡度上限 10°、22°、30° × 70 栋目标，共 12 组，每组同时验证适应性与随机对照。22°/30°下均达到 70 户；10°下为 35–46 户，仍满足约束。

## 使用

直接用 Chromium/Edge 打开项目根目录 `mountain-village.html`，无需安装依赖或 API Key。城市工作台顶栏新增了入口。也可运行 `npm run serve:village`，访问 http://127.0.0.1:5190/mountain-village.html 。预览服务器只监听本机，提供白名单项目文件。

`village.html`、`village.css` 和 `src/village-app.js` 是开发源文件；`npm run build` 同时生成城市与村落的独立 HTML。文档链接需要保留旁边的 docs 目录，主交互与 JSON 导出不依赖这些链接。

## 已实现的算法

- **确定性地形**：400×400m，5m 采样网格；连续高斯山脊和低幅正弦变化，种子控制山脊偏移。水域为预设椭圆掩膜，不包含真实水文。
- **硬约束**：旋转建筑中心与四角均避让水域和边界，坡度不超过用户上限；建筑中心间距至少 22m；道路与住宅保留圆盘安全净距。建筑体块为 10×8m。
- **选址**：每轮确定性采样 180 个候选，按兴趣评分排序，并尝试前 14 个可行候选的接路。评分由平缓偏好（0.38）、靠路偏好（0.28）、中心吸引（0.20）、邻居间距偏好（0.14）及最多 0.06 的种子扰动组成。
- **道路**：入口先连到中心；新增住宅入口通过 8 邻域 A* 接入已有道路顶点。边成本为 `length × (1 + 20 × longitudinalGrade²)`，纵坡大于 32% 的边被拒绝。直线距离是可采纳启发函数。成本依赖本段方向的纵坡，不含转弯项，搜索状态无需额外方向维度。
- **反馈**：每放置一栋住宅便扩展道路，下轮候选依靠更新后的道路距离评分。先完成布局再保留逐步事件，时间轴是确定性结果回放。
- **建筑预览**：等高线朝向、三段基础和简单双坡屋顶。Canvas 等距三维可同步旋转缩放，也可切俯视图；该轻量预览没有完整地形深度缓冲。

### 适宜性和评分的区别

热力图显示的是地形条件（坡度、水域），不是完整动态兴趣评分。道路距离、中心和邻居偏好参与实际候选评分；每步的最终兴趣评分及新增接路长度显示在时间轴下方，并保存在事件数据里。

### 中止条件

生成目标为 10–70 栋，默认 50 栋。若在 `count × 12` 轮预算内没有足够位置，返回 `capacity-limited` 和实际建筑数，界面显示“达到当前布局预算”。这不意味着证明整个场地的理论容量，只表示该启发式算法在本次预算下找到的结果。

## 网格基线与指标

基线使用相同地形、相同建筑预算和体块尺度，采用固定 50m 间距的纵向道路、入口端横路和按行布置的住宅。基线住宅避让水域，但不以坡度优化选址；其道路也不绕开水域或陡坡。这是用于暴露规则网格局限的**实验基线**，并非原城市编辑器的完整算法迁移，不是等优化强度的科学基准。

- 建筑坡度：取中心和四角采样坡度的最大值，均值为所有可见建筑的均值。
- 建筑超坡/涉水：按当前阈值与水域掩膜计数。
- 道路长度：水平 X/Z 平面长度；相同端点的重复网格边只计一次。
- 道路超坡/涉水长度：按每条离散边的端点高差，以及端点/中点水域采样判定；两类可能重合，不能直接相加视作不合格总长度。
- 时间轴两侧显示同一建筑阶段；基线固定路网在第零步就存在。
- 道路连通：每条新增道路起点必须是已有道路节点，且每栋住宅的入口点必须在网络上。

所有阈值都是实验参数，尤其 32% 纵坡不表示符合公共道路设计要求。这里没有道路规范、真实土方优化或社会经济预测。

## 数据与代码

- `src/village.mjs`：纯函数生成、地形采样、寻路、网格基线、指标和验证。
- `src/village-app.js`：Canvas 预览、参数、回放、比较和导出。
- `src/village-households.mjs`：有向成本宅地竞争、边界、入口步道、朝向与阶梯基础。
- `tests/village-households.test.mjs`：宅地单元唯一性、连通、边界面积、水域/道路避让、住宅/步道包含、随机对照和非法数据检出。
- `tests/village.test.mjs`：确定性、几何/接路约束、多种子、容量限制和指标回归。
- `tests/standalone.test.mjs`：构建并编译两个 HTML 内联脚本，防止打包命名冲突和残留外部脚本依赖。

导出的 JSON 包含版本、模型标识、参数、地形数组、住宅、道路、生长事件、基线、指标、当前回放阶段与论文来源。它是该实验的结果数据；目前不支持直接导入原城市编辑器。

## 研究来源与实施边界

1. [Emilien et al., 2012 — Procedural Generation of Villages on Arbitrary Terrains](https://perso.liris.cnrs.fr/egalin/Articles/2012-villages.pdf)：借鉴选址与道路交替增长及兴趣图思想。
2. [Galin et al., 2010 — Procedural Generation of Roads](https://perso.liris.cnrs.fr/egalin/Articles/2010-roads.pdf)：借鉴方向相关成本的道路选线思想。

本实验的权重、采样、网格 A*、宅地竞争和建筑预览是面向浏览器的简化实现，不是论文完整复现。宅地采用本文独立定义的有向成本区域生长，不等于原文征服法的完整复现。完整开放形状语法、真实 GIS、日照、水文和桥隧尚未实现。
