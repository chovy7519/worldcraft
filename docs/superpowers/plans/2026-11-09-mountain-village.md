# Mountain Village Implementation Plan

**Goal:** 在既有 WorldCraft 旁交付可离线运行的山地村落实验，包含约 50 栋建筑、环境图、道路反馈、生长回放和网格对照。

**Architecture:** 独立的纯函数布局模块生成确定性地形、建筑、道路和生长事件；Canvas 等距三维视图展示结果；独立 HTML 构建不影响原城市数据合同。

**Tech Stack:** 原生 JavaScript、Canvas 2D、Node test runner，无外部运行依赖。

**Spec:** 用户已选择山地村落；范围承接本聊天确认的实验方案。研究依据见 ../../PROCEDURAL_SETTLEMENT_RESEARCH.md。

## Global Constraints

- 400×400 米地形；默认目标 50 栋，预算不足时明确显示实际数量。
- 适应性模式的建筑避让水域、过陡地形、其他建筑和道路；道路连接入口并受纵坡限制。
- 网格基线明确标注为实验对照，不伪称为现有城市生成器的同地形输出。
- 支持种子、数量、坡度限制、生长时间轴、播放暂停、热力图、二维/三维及 JSON 导出。
- 研究启发的简化实现，不宣称复现完整论文或工程规划模拟。

## Review Focus

无效参数、无法达到目标时的反馈、路径跨水/撞建筑、时间轴首尾状态、手机布局与离线构建。
