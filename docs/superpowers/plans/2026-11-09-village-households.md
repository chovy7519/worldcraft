# Mountain Village Households Implementation Plan

**Goal:** 生成可逐户查看的宅地、入口、入户步道、等高线朝向与阶梯基础，并加入坡度随机对照。

**Architecture:** 新建纯函数 `village-households.mjs` 负责旋转建筑几何与有向成本的多源栅格宅地生长。原村落生成器负责地形、选址和道路，生成完成后关联宅地；新对照仅移除选址的道路/邻里/中心评分，共享硬约束、寻路和建筑规则。页面支持对照选择、宅地图层和逐户检查。

**Tech Stack:** 原生 ES modules、Canvas、Node test，无新增依赖。

**Spec:** 用户同意上一轮建议中的前两项（真实宅地、响应宅地与山势的住宅），同时补充坡度随机基线；本轮不新增公共中心系统或 Houdini 集成。

## Global Constraints

- 保留现有离线 HTML 构建、城市编辑器和回放。
- 宅地为 2.5m 栅格多边形：四邻域连通、单元唯一归属、道路与水域为障碍，保留公共未分配土地。
- 建筑及入户步道必须在所属宅地内；明确道路接触边与门/院门/接路点。
- 长边沿局部等高线；入口从正面连接道路；基础按等高线方向的三个条带形成不同标高。
- 阈值仍是视觉实验参数，不作工程或完整论文复现声明。
- 坡度随机对照使用独立固定随机流、同地形/预算/阈值/寻路/宅地规则；容量不足如实显示。

## Review Focus

道路切开宅地、旋转房屋四角越界、步道穿越邻户、基础埋入地形、对照预算不足与回放选择同步、单文件模块依赖。
